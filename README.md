# Unity 3D 道具拖曳生成與物理互動系統

本專案為使用 **Unity 6 (6000.6.7f1)** 開發之 3D 桌面應用程式，實現了一套具備自適應介面、有限範圍起伏曲面、可折疊道具選單、真實物理拋物線軌跡指引、碰撞著地彈跳與 3D 物件互動刪除的完整系統。

---

## 成果展示影片

- **影片連結**：`[https://youtu.be/owDXMqMKl3s]`
- **展示內容涵蓋**：
  1. 自由縮放視窗大小，驗證 UI 自適應比例。
  2. 右側道具 Dropdown 點擊展開/收合與動態箭頭反饋。
  3. 道具拖曳生成、游標跟隨與動態漸層物理拋物線軌跡。
  4. 拖曳防呆判定：落於 UI 面板或無場景位置時動作取消不生成。
  5. 物理碰撞與動態表現：著地彈跳、順應坡度自然滾動。
  6. 掉出地表邊界自動銷毀清理機制。
  7. 點選場景道具彈出 3D 浮動選單，點選「刪除 (Delete)」銷毀物件。
